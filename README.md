###### **Password Strength Checker**

###### 

###### A beginner cybersecurity project written in Python that validates passwords based on common security requirements.

###### 

###### **Features**

###### 

###### This program checks whether a password:

###### 

###### Is at least 8 characters long

###### Contains at least one uppercase letter

###### Contains at least one lowercase letter

###### Contains at least one number

###### Contains at least one special character

###### Matches the confirmation password

###### Does not contain the username

###### 

###### If all requirements are met, the account is created successfully.

###### 

###### **How It Works**

###### 

###### The user enters:

###### 

###### Username

###### Password

###### Password confirmation

###### 

###### The program then validates the password against several security rules and displays an appropriate message.

###### 

###### **Example**

###### 

###### Enter username: john

###### 

###### Enter password: Password123!

###### 

###### Repeat password: Password123!

###### 

###### Account created successfully.
